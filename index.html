What it does

⌨️

Phonetic typing

Smart suggestions and autocorrect for Hindi/Gujarati spelled in Latin letters — handles spelling variants like "kaise" / "kese" automatically.

🎙️

Voice input

Tap, speak a full sentence, tap again — get the same Latin-letter text. Runs fully on-device, no cloud, built for messaging.

📋

Clipboard history

A real clipboard manager built in, not bolted on.

🔒

Private by design

No account, no cloud, no ads. Everything — typing and voice — runs on your phone.

Install

  1. Download the APK below and open it on your Android phone (allow "install from unknown sources" if asked — this app isn't on the Play Store).
  2. Go to Settings → System → Languages & input → On-screen keyboard and enable Freech.
  3. Switch to Freech from the keyboard-switcher icon while typing.

Built in the open

Freech is being built sprint by sprint, in the open, by a small AI-assisted development team — a manager coordinating research, engineering, and testing roles against a public sprint plan. Every architectural decision (on-device voice recognition, Latin-letter output instead of script conversion, free-forever with no cloud dependency) is documented before it's built, not decided after the fact.

The source stays private while the product takes shape, but every build that reaches this page is real, tested code — not a mockup. What you download here is exactly what shipped from that process.

Freech is free and runs entirely on-device. No account, no cloud, no ads.
