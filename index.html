Freech

Type Hindi and Gujarati in Latin letters — the way you already text.

Not a translator. You type kem cho, you get kem cho — spelled and suggested correctly, instead of your keyboard treating it as broken English.

Download latest APK  

Install

  1. Download the APK below and open it on your Android phone (allow "install from unknown sources" if asked — this app isn't on the Play Store).
  2. Go to Settings → System → Languages & input → On-screen keyboard and enable Freech.
  3. Switch to Freech from the keyboard-switcher icon while typing.
